## 页面里那些影响开服的细节

**住宅 IP 系列不开放 80 和 443 端口。** 页面把这写成 IP 风控的结果。Minecraft 走的是自己的游戏端口，不开 80/443 不影响玩家进服；但你如果想挂网页地图、网页控制台，让朋友用域名直接打开，这一类就不合适。

**IRVINE-PRO 系列默认拒绝外部探测和扫描。** 页面原话是“访问受限，除非完成配置，只有白名单或端口转发过的设备才能访问”。这适合私密服，公开招人的公益服会很麻烦。同一系列还写了一条：退款只能退到网站账户余额。

**流量不是问题。** 5TB 到 40TB 的月流量，一个十几人的 MC 服一个月跑不到零头，选档时不用看这一列。

**CPU 主频偏低。** Minecraft 服务端吃单核性能。第三方测评里，2024 年那批 AT&T 住宅 IP 机器测出来主频 2.8GHz 且看不到具体型号，2026 年 7 月另一篇测评写的是 EPYC 2.0GHz。跑十几人的原版服没问题，几十人加上大量实体和红石机器就会掉 tick。想要高主频，得去看面板服那边标 5.5GHz、5.7GHz 的档位。

## 常见问题

**几个人要多少内存？**
2 到 4 人原版 2GB 起步，6 到 10 人原版或带插件 10 人 4GB，小型整合包 6GB，大多数整合包 8GB，需要 10GB 以上的重载包 12GB 起。内存不够的表现是服务端频繁 GC、玩家看到方块回弹，而不是直接崩服，容易被误判成网络问题。

**Java 和基岩能一起玩吗？**
能。Java 服装 Geyser，手机、平板和 Windows 基岩版的玩家可以进同一个世界。面板服一般有开关，VPS 上要自己装，还要额外放行一个 UDP 端口。主机端（Xbox、PS）进不了 Java 服，那是另一套。

**能中途换 Minecraft 版本吗？**
VPS 上你自己装，换版本随时可以。要注意的是换到比现有世界更旧的版本，地图里的新方块会丢失，稳妥做法是开新世界、把旧世界留在硬盘里。面板服在控制面板的 Advanced 标签页里换，换之前会自动备份，起不来会回滚。

**取消之后存档还在吗？**
面板服的政策写得比较清楚：wikily 试用期结束停服后世界保留 3 天，正式取消保留 14 天，期内续订可以接着玩。VPS 没有这层保护，机器释放后数据就没了。取消前务必用 SFTP 把整个 world 文件夹拉回本地，这一步别省。

**国内玩家延迟怎么选节点？**
玩家在国内，优先国内节点（广州、上海、北京、成都、南京），其次亚洲的新加坡。玩家在北美或欧洲，才轮到洛杉矶。用 CN2、AS9929 这类优化线路的机器，回国质量比普通国际带宽好，但和“把服务器放在国内”是两件事。
